🛡️ TrustGuard AI

TrustGuard AI is an intelligent cyber-risk analysis dashboard designed to detect and prevent digital threats across multiple input formats using AI-driven techniques.

It enhances user safety by analyzing messages, URLs, audio, and QR codes for potential risks in real time.


🚀 Features

🔍 Text Analysis
Detects phishing attempts and social engineering patterns using heuristic and behavioral AI.
🌐 URL Scanning
Identifies malicious links using signature detection and typosquatting analysis.
🎙️ Audio Risk Analysis
Converts speech to text and evaluates verbal content for potential threats.
📷 QR Code Inspection
Scans QR codes to detect unsafe or hidden redirection targets.


💡 Project Vision

With the rapid increase in cyber threats, TrustGuard AI aims to provide a unified security layer that can analyze multiple input types and warn users before they fall victim to scams or attacks.
