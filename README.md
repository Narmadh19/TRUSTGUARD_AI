TrustGuard AI
TrustGuard AI is an advanced cyber-risk analysis dashboard that uses AI to detect threats in messages, URLs, audio, and QR codes.

Features
Text Analysis: Scan messages for social engineering patterns using heuristic and behavioral AI.
URL Scanning: Check links for malicious signatures and typosquatting.
Audio Risk Scan: Automatic transcription and verbal threat analysis.
QR Code Inspection: AI-powered vision scanning for deep QR target analysis.
Setup Instructions
Clone the repository
Install dependencies: npm install
Configure environment: Create a .env file with your GEMINI_API_KEY.
Run development server: npm run dev
Deployment
This app is optimized for deployment on Firebase App Hosting or any Next.js compatible platform.
