# **App Name**: RiskGuard AI

## Core Features:

- Multi-Input Risk Analysis: Scan user-provided text or URLs for suspicious keywords, patterns, and indicators of potential threats, providing an instant risk score.
- Audio Transcription & Risk Scan: Upload audio files (.wav format), automatically transcribe spoken content to text using an external AI service, and then analyze the transcribed text for security risks.
- QR Code Content & Risk Scan: Allow users to upload QR code images (.png), automatically extract the embedded text or URL, and perform a comprehensive risk analysis on the extracted content.
- Dynamic Risk Visualization: Visually represent the calculated risk score (0-100), risk level (Safe, Medium, High), and highlighted suspicious elements through interactive gauges and clear textual indicators.
- AI-Powered Risk Summary Tool: Leverage a generative AI tool to provide a concise explanation of *why* an input was flagged as risky, identify the specific threat vectors, and suggest immediate mitigation steps.

## Style Guidelines:

- Dark mode for a professional, cyber-security aesthetic. The background color is a deep, desaturated indigo (#1E1E2F), providing a subtle yet rich base. Primary color: A vibrant, purplish-blue (#6854F7) for interactive elements and key data points, creating a strong contrast against the dark background. Accent color: A bright, clear sky blue (#8BC9FF), analogous to the primary hue, used for highlights, alerts, and to draw attention to critical information.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, techy, and slightly futuristic feel. Body text font: 'Inter' (sans-serif) for high readability, objectivity, and a clean, functional look suitable for data display and detailed information.
- Use clear, concise line icons that convey functionality at a glance (e.g., text, URL, audio wave, QR code symbol). Employ universally recognized status icons (checkmarks, warning triangles, crosses) for risk levels, styled with vibrant colors corresponding to their severity.
- Adopt a 'wide' dashboard layout using a card-based system to neatly organize different analysis modules (Text, URL, Audio, QR Code). Emphasize visual separation for ease of navigation, and responsive design for optimal viewing across various devices. Key metrics and visualizations are centrally prominent.
- Implement subtle, smooth transitions for risk gauge updates and score changes to provide engaging visual feedback. Employ slight hover effects on interactive elements and module cards to enhance user experience and convey interactivity without being distracting.
